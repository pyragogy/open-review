About Pyragogy

What is Pyragogy?

Pyragogy is an open AI-powered tool by Fabrizio Terzi — an ecosystem of specialized agents forming an AI Orchestra within an AI Village. It synchronizes human and machine intelligence to engage with the living patterns of the Peeragogy Handbook and brings peer learning into the era of collaborative, distributed intelligence.

The Orchestra

The Live Lab Orchestra is one instrument in a larger ensemble. Each agent carries a distinct epistemic posture — not a role, but a mode of attention. The Complicit Editor does not resolve the tension between them. It names it. That friction is the document.

Orchestration Stack

The pipeline runs on n8n with models served via OpenRouter. No data is stored server-side. Your API key lives only in the request. The revision belongs entirely to you.
